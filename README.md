CaptionLite - Live Caption App

How to use:

1. Double click CaptionLite.exe
2. Click "Start"
3. Play any video or audio
4. Captions will appear on screen

Notes:

* Works best with speech (videos, lectures)
* For games, use "Borderless Windowed Mode"
* Internet is NOT required (offline)

If Windows shows a warning:
Click "More Info" → "Run Anyway"

If any bug, then may force Close by selecting "End Task" in Task Manager.
